# Ajio Clone

A responsive front-end clone of the Ajio e-commerce website built with HTML, CSS, and JavaScript.


## Getting Started

1. Clone the repository:
   ```
   git clone https://github.com/CodemaxAI/Ajio-clone.git
   ```

2. Navigate to the project folder:
   ```
   cd Ajio-clone
   ```

3. Open `index.html` in your browser to view the website.
